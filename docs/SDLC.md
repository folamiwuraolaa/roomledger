# SDLC and Software Engineering Activities

## 1. Planning
Define the shared dorm expense problem, stakeholders, scope, constraints and success criteria.

## 2. Requirements Engineering
Elicit member/admin needs, write functional and non-functional requirements, define acceptance criteria and build a requirements traceability matrix.

## 3. Analysis
Model use cases, data flows, domain rules, roles and risks. Identify manual spreadsheet/chat-based pain points.

## 4. Architectural Design
Select React/TanStack for the interface, Flask for the API and SQLAlchemy for persistence. Use PostgreSQL/Supabase for deployment.

## 5. Detailed Design
Design database entities, API contracts, authentication, RBAC, page navigation, settlement flow and error handling.

## 6. Implementation
Implement authentication, household management, expense splitting, balance calculations, settlement recording, notifications, receipts and Super Admin controls.

## 7. Testing
Perform unit tests for ledger arithmetic, integration tests for API workflows and system/UI tests for complete user journeys.

## 8. Deployment
Configure Vercel frontend variables, Supabase PostgreSQL and secure production cookies/secrets.

## 9. Maintenance
Fix defects, monitor errors, update dependencies, improve usability and add future enhancements without weakening accounting correctness.
