# User Manual

## Member
1. Open Sign Up.
2. Choose **Member**.
3. Select your household from the available list, or use the admin invite code.
4. Create your account.
5. Use **Add Expense** to record a shared purchase.
6. Select who paid and who participated.
7. Open **Balances** to see what you owe and what others owe you.
8. Use **Settle** to record a payment.

## Household Admin
1. Choose **Household Admin** during registration.
2. Complete household creation.
3. Share the household invite code.
4. Use Household management to change roles or remove settled members.

## Super Admin
1. Visit the one-time Super Admin setup page.
2. Create the single system-level account.
3. After creation, the setup page becomes disabled.
4. Log in to the Super Admin dashboard to review system-wide users, households, expenses and settlements.
